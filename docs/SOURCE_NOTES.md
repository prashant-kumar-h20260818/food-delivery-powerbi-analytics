# Source & Attribution Notes

This portfolio project is an **original implementation** inspired by the learning structure of:

- Sheryians AI School — *Build an End-to-End Business Analytics Dashboard in Power BI (Food Delivery App Data)*
- YouTube: https://www.youtube.com/watch?v=xj-ByfvYtuQ
- Instructor: Dhanesh Malviya

The tutorial describes an end-to-end workflow covering Power Query ETL, Orders/Customers/Restaurants/Date modeling, DAX, executive/customer/restaurant/delivery analysis, advanced features, and drill-through.

## Important
The dataset in this repository was generated specifically for this portfolio implementation.
It is **not** copied from Zomato, Swiggy, the instructor's Google Drive, or another GitHub user's PBIX file.
Restaurant names and records are fictional.
